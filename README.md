# Baptism of Calix Jace — Invitation

A single-page baptism invitation landing page.

- **Event:** Baptism of Calix Jace
- **When:** Sunday, 27 December 2026, 10:00 AM
- **Church:** Our Lady of Fatima Parish Church, Lawa, Calamba
- **Reception:** Brgy. Kay Anlog, Villa E Javier, Blk 17 Lot 11

## Files

- `index.html` — the full page (HTML, CSS, and JS inline)
- `assets/hero.jpg` — the hero photo

This is a static site. No build step is required — it can be served as-is.

## Local preview

Open `index.html` in a browser, or run a simple static server:

```powershell
npx serve .
```

## Deploy (Vercel)

This repo is deployed on Vercel as a static site. Vercel auto-detects it; no
framework or build command is needed. `vercel.json` sets long-lived caching for
images and clean URLs.
